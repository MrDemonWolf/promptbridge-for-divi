## What works today

- Add a separate **Generate with PromptBridge** action to the Divi 5 Text
  module's Body field.
- Queue a text request for the server's separately installed Codex runtime.
- Show the returned text in a preview. The editor must choose **Apply to Divi
  field** before the page changes.
- Let an administrator check the runtime and refresh the available model list
  from the plugin settings.

An administrator must accept the current Terms of Use and acknowledge the
Privacy Policy. They must also separately enable Codex service access before
text can be sent for generation. See [Security and privacy](/docs/security).

## What is not included or proven

- PromptBridge does not install, update, or sign in to Codex.
- Image generation is not implemented.
- Production reliability, cPanel support, and all Divi save/undo behavior have
  not been proven.
- WordPress.org approval is not claimed.

Read [Limitations and gates](/docs/limitations) before using the plugin on a
live site.

## Recorded staging check

The latest documented staging check used licensed Divi 5.13.1 and Codex CLI
0.155.1 installed at a server-owned path. This is evidence for that setup only;
it does not prove compatibility with every host, account, or Divi version.
