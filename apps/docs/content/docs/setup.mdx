## What you need

- WordPress 6.7 or newer
- PHP 8.3 or newer
- Divi 5
- A server where PHP <code>proc_open</code> is allowed
- A server owner who can install Codex and edit <code>wp-config.php</code>

## 1. Ask the server owner to prepare Codex

The server owner must create a dedicated Codex home for this site. It must be
outside the public website folder, private to the PHP worker, and set to
directory mode 0700. Add an empty <code>.promptbridge-for-divi</code> marker
file to that folder.

Add these server-owned settings to <code>wp-config.php</code>:

```php
define( 'MDW_PBD_CODEX_PATH', '/absolute/path/to/codex' );
define( 'MDW_PBD_CODEX_HOME', '/private/path/to/promptbridge-codex-home' );
```

Sign Codex in using that dedicated home. Do not copy a developer workstation's
Codex folder or credentials.

## 2. Install PromptBridge

1. Download the CI or release ZIP.
2. In WordPress, open **Plugins > Add New > Upload Plugin**.
3. Upload the ZIP, select **Install Now**, then **Activate**.

## 3. Accept the policies and choose service access

Open **Divi > PromptBridge**. If Divi's menu is unavailable, look under
**Settings > PromptBridge**.

1. Accept the current Terms of Use and acknowledge the Privacy Policy. WordPress
   requires this before plugin settings are available.
2. Read the service disclosure.
3. Enable **Allow Codex service access** only if you want editors to request
   text generation or an administrator to refresh the model list.

This is an explicit opt-in. When an editor requests a draft, their instruction
and the selected Text field content are sent to OpenAI through the separately
installed Codex runtime.

## 4. Check the server setup

Select **Run diagnostics**. PromptBridge checks the local runtime and, with
service access enabled, refreshes the model list. Nothing runs on page load. The
diagnostic response is bounded and validated before model names are saved.

## 5. Test one Text field

Use a disposable staging page so you can safely practice.

1. Open the page in Divi's Visual Builder.
2. Open a Text module and find its **Body** field.
3. Select **Generate with PromptBridge** and enter a short instruction.
4. Wait for the separate preview. If the request stays queued, check that
   WordPress Cron can run; cPanel sites may need a
   [scheduled cron](/docs/cpanel).
5. Review or edit the draft, then select **Apply to Divi field** if you want to
   use it.
6. Save the page in Divi and reload it to check the result.

## If something goes wrong

- **Codex runtime unavailable:** ask the server owner to check both paths in
  <code>wp-config.php</code>, the private folder permissions, and whether
  <code>proc_open</code> is allowed.
- **Request stays queued:** check WordPress Cron. On a low-traffic site, a host
  cron may be needed; see [cPanel setup](/docs/cpanel).
- **You are unsure what gets sent:** read [Security and privacy](/docs/security)
  before enabling service access.

## Important boundary

PromptBridge never downloads, installs, updates, replaces, or removes Codex. The
server owner manages Codex independently.
