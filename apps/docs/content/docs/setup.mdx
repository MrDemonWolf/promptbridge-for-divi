## Requirements

- WordPress 6.7 or newer
- PHP 8.3 or newer
- A server where `proc_open` is permitted
- Divi 5 for the Text module Body action
- An official Codex installation managed by the server owner

## Install

1. Download the CI or release ZIP.
2. Upload it through **Plugins > Add New > Upload Plugin**.
3. Activate **PromptBridge for Divi**.
4. Add server-owned configuration to `wp-config.php`:

```php
define( 'MDW_PBD_CODEX_PATH', '/absolute/path/to/codex' );
define( 'MDW_PBD_CODEX_HOME', '/private/path/to/promptbridge-codex-home' );
```

5. Sign Codex into that dedicated home. Do not copy a developer workstation's
   global Codex home or credentials.
6. Open **Divi > PromptBridge**.
7. Review the OpenAI service disclosure and choose whether to opt in.
8. Select **Run diagnostics**.

After consent, **Run diagnostics** executes the fixed local commands for the
version probe and `codex debug models --bundled`. The model response is capped
at 2 MB and strictly projected so only list-visible API models are cached in the
non-autoloaded `mdw_pbd_model_catalog` option. The raw 443 KB catalog is not
stored, and a failed refresh preserves the last-good cache. Refresh occurs only
when this action is clicked. In the current Codex 0.155.1 staging result, the
five models are Astra, Sol, Terra, Luna, and 5.5, with Luna as the default and
fallback.

The Codex home must be dedicated to this plugin, writable by the PHP worker,
outside the public WordPress directory, and set to directory mode `0700`. Add an
empty `.promptbridge-for-divi` marker file to confirm the path is reserved. Do
not reuse a development account's global Codex home.

The Divi Text Body action queues generation through WordPress Cron. A cPanel
host may need a system cron that runs `wp-cron.php`; see the
[cPanel setup](/docs/cpanel). The Codex App Server protocol is experimental, and
target-host compatibility is not guaranteed.

## No runtime installer

PromptBridge never downloads, installs, updates, replaces, or removes Codex. The
host owner manages Codex independently.
