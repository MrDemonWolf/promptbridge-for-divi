## What leaves your site

When an editor requests a draft, PromptBridge sends their instruction and the
selected Divi Text field content to OpenAI through the separately installed
Codex runtime. The runtime uses the account signed in to its dedicated Codex
home.

Plugin activation and page load do not contact OpenAI. WordPress update checks
may separately send the server IP address and ordinary request details to GitHub
to check for releases.

## What WordPress stores

- While a job is queued or running, the request text is held in a private
  WordPress job.
- PromptBridge removes the instruction and source text when the job finishes or
  fails.
- The preview and job details are scheduled for deletion after one day.
  WordPress Cron can run late, so cleanup may happen later.
- The Codex runtime may keep its own session history in the dedicated Codex
  home. PromptBridge does not manage or delete that history.

## Who can request a draft

- A site administrator must accept the current Terms of Use and acknowledge the
  current Privacy Policy.
- An administrator must separately enable **Allow Codex service access**.
- The editor must be signed in, have permission to edit that page, and have the
  PromptBridge generation capability.
- WordPress checks permission and consent again before the background job
  starts. Turning off consent prevents queued work from starting.

See the [Terms of Use](/docs/terms) and [Privacy Policy](/docs/privacy) for the
full policies. Also review
[OpenAI's privacy policy](https://openai.com/policies/privacy-policy/) and
[terms of use](https://openai.com/policies/terms-of-use/).

## What PromptBridge protects

- WordPress verifies the signed-in user, page-edit permission, current policy
  acceptance, and service consent.
- The browser cannot choose a Codex executable or add command-line arguments. A
  server owner sets the absolute path and private Codex home in
  <code>wp-config.php</code>.
- Codex runs as a local process over stdio. PromptBridge does not expose an
  app-server network port.
- Runtime time and output are bounded. Model catalog data is size-limited and
  validated before it is cached.
- Diagnostic output is escaped before it is displayed.
- Activation makes no external request and installs no dependency.

## Generated code

PromptBridge does not execute generated PHP or JavaScript. The current action is
for text in a Divi Text module.

## Uninstall

Uninstall removes PromptBridge's settings, scheduled work, and capabilities. It
preserves published pages, media, the separately installed Codex executable, and
credentials it does not own.
