## Server and account behavior

- <code>codex app-server</code> is experimental. Production support and
  reliability have not been established.
- The plugin uses a Codex account already signed in to the dedicated server-side
  Codex home. Login, refresh, and account-management flows are not provided by
  the plugin.
- WordPress Cron may delay queued work. cPanel and other shared-host
  compatibility have not been confirmed.

## Divi behavior

- PromptBridge adds a separate action to the Text module. It does not intercept
  or replace Divi's built-in AI action.
- A live test must still confirm Divi undo, responsive field values, and
  save/reload behavior on supported versions.
- Apply checks that the text has not changed while a draft was running, but this
  check alone does not prove every editor-state behavior.

## Features and release status

- Image generation is not implemented. A separately billed OpenAI Image API
  request would not prove Codex subscription-based image generation.
- WordPress.org eligibility and approval are unknown. Passing Plugin Check does
  not mean the plugin has been approved.
- Trademark and plugin slug clearance have not been established.

Treat staging results as evidence for the exact versions and host tested. They
are not a production compatibility promise.
