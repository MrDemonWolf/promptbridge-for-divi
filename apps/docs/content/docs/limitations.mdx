---
title: Limitations and gates
description: Claims this staging alpha does not make.
---

The following items are unproven:

- production support or stability of `codex app-server`;
- ChatGPT-managed login, refresh, disconnect, and cancellation on the target
  host;
- subscription-backed image output through a custom app-server client;
- shared cPanel support for persistent or queued Codex work;
- interception of only Divi's built-in AI action;
- undo, stale-result protection, responsive values, and save/reload behavior;
- WordPress.org eligibility or approval; and
- trademark or slug clearance.

The separately billed OpenAI Image API is not a substitute for the requested
subscription-backed image proof. Passing Plugin Check is not directory approval.
